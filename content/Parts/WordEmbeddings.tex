\subsection{Problems of One-Hot Encoding}

\begin{itemize}
  \item \textbf{Sparsity}: the vectors are sparse, this leads to scalability issues. A standard vocabulary can have 50K words, implying a 50K-dimensional vector for each word. The vector space is not used efficiently
  \item \textbf{Orthogonality}: the is no preservation of similaruty or relationships. Here, all pairs of words have exactly the same
\end{itemize}

\subsection{Solving the right task}

\begin{flushleft}
  \begin{minipage}{0.65\linewidth}

    \begin{enumerate}
      \item assign a vector for each words in the context, at beginning is random number
      \item Take all of this vector and aggregate all vectors and sum them up (\textbf{context vector})
      \item Assign a vector for each candidate output word, at beginning is random number
      \item Compute the distance between the context vector and all possible output words (e.g., via dot product)
      \item Find the word that best matches the context
      \item Is it the correct word?
      \item Adjust all vectors accordingly (via gradient descent)
    \end{enumerate}

\section{In terms of matrices}

\begin{flushleft}
  \begin{minipage}{0.65\linewidth}

    We need to compute a matrix moltiplication. All vectors for input and output words can be staked into matrix $W_{in}(d \times V)$ and $W_{out}(d \times V)$.

    The entire context can be represented a binary vector of presences, $e(V\times 1)$.

    \begin{tcolorbox}
      \textbf{Note:} This loses the order of the words, \textbf{bag of words} approach.
    \end{tcolorbox}

    $ h = W_{in} e(d \times 1)$ computes the sum of the vectors for the context words.

    Where $e_j$ acts as a selector of the $j^{th}$ column within $W_{in}$.

    Next, we search among the vectors in $W_{out}$, the most
    similar to $h$. We can use the dot product as a measure of similarity. ("How aligned are the vectors?").

    $\tilde{p} = h^T W_{\text{out}}$ is a vector of similarities between $h$ and each possible word.

    We can normalized the values in $\tilde{p}$ be positive and sum to 1 $p_i = \text{softmax}(\tilde{p}_i)$.


    Remember, we know what the correct target word is. We can use a cross-entropy loss to update $W_{in}$ and $W_{out}$.

\section{Neural Language Models & word2vec}

This was presented in a paper of 2000. Then in the 2014, thirty years later.

word2vec does all of the previous things, with some caveats.

Two possible tasks:

\begin{itemize}
  \item \textbf{Continuous Bag of Words}: context è predict middle word $\to$ as previously described
  \item  \textbf{Skip-gram}: middle word $\to$ predict context
\end{itemize}

Workarounds to prevent computing softmax (computationally expensive!)

\begin{itemize}
  \item \textbf{Hierarchical softmax} Huffman encode vocabulary, predict left/right path $O(\log_2(V))$
  \item \textbf{Negative sampling} predict whether a word is/is not the "correct" one
\end{itemize}


\subsection{Limitation of WordToVec}


While word2vec addressed many problems, some still exist. Among
others

\begin{itemize}
  \item \textbf{Inability to handle out-of-vocabulary words}: Cannot manage words are not in the vocabulary, OOV (out of vocabulary)
  \item \textbf{Lack of contextualized vectors}: This vector are not contextualized. After the training, the vector is fixed and not affected by context, but during the infference some word depends on the context, e.g. bank (river or money).
\end{itemize}
